## 1. 已验证的系统结构

- A板：手持遥控器，读取 PS2 双轴摇杆并通过 ESP-NOW 发出控制数据。
- B板：车辆控制器，接收控制数据，驱动 TB6612FNG 和 MG995。
- V1驱动方式：两个后轮同速前进/后退，前轮由舵机转向。
- 无线信道：ESP-NOW Channel 6。
- A板 Wi-Fi STA MAC：`44:B1:76:08:40:2C`。
- B板 Wi-Fi STA MAC：`44:B1:76:07:B4:C0`。
- 失联保护：超过100ms未收到有效数据，电机立即停止、TB6612进入待机、舵机回中并解除锁定。

## 2. 总体电源连接

车辆使用4节AA镍氢电池作为主电源。主开关应位于电池正极与所有负载分支之前。

```text
4节AA镍氢电池正极
        │
        ├──→ TB6612 VM（电机功率电源）
        │
        ├──→ MG995 红线（舵机功率电源）
        │
        └──→ 5V升降压模块 IN+
                         OUT+ ──→ B板 ESP32 的 5V 引脚

4节AA镍氢电池负极
        │
        ├──→ TB6612 GND
        ├──→ MG995 棕色/黑色线
        ├──→ 5V升降压模块 IN-
        ├──→ 5V升降压模块 OUT-
        └──→ B板 ESP32 GND
```

所有GND必须共地，否则ESP32输出的电机和舵机控制信号没有共同参考电位。

### 2.1 电压要求

| 电源网络 | 正常电压 | 用途 |
|---|---:|---|
| 4节AA镍氢电池 | 标称4.8V，充满约5.2～5.6V | 电机、舵机和升降压模块输入 |
| 升降压模块输出 | 4.9～5.1V | B板 ESP32 的5V输入 |
| ESP32 3.3V输出 | 约3.3V | TB6612 VCC逻辑电源 |

### 2.2 严禁事项

- 不得把电池正极直接接到ESP32的3.3V引脚。
- 不得用ESP32的3.3V或5V引脚给MG995供电。
- 不得让电机或舵机主电流经过面包板、杜邦线或ESP32开发板。
- 不得把USB 5V与升降压模块5V输出直接并联。
- 不得在通电状态下移动或重新插拔电源线。

## 3. A板遥控器接线

PS2摇杆模块虽然将电源脚标为`+5V`，本项目必须接ESP32的3.3V，使VRx和VRy模拟输出不会超过ESP32 ADC范围。

| PS2摇杆模块 | A板 ESP32-C3 | 说明 |
|---|---|---|
| GND | GND | 地线 |
| +5V | 3.3V | 这里只接3.3V，不接5V |
| VRx | GPIO0 | 左右转向模拟量 |
| VRy | GPIO1 | 前后油门模拟量 |
| SW | GPIO2 | 摇杆按键，低电平有效 |

已测摇杆校准值：

| 位置 | VRx | VRy |
|---|---:|---:|
| 中心 | 约2210 | 约2239 |
| 最左 | 0 | 约2236 |
| 最右 | 4095 | 约2238 |
| 最前 | 约2210 | 0 |
| 最后 | 约2210 | 4095 |

控制定义：

- 摇杆向前：正油门，车辆前进。
- 摇杆向后：负油门，车辆后退。
- 摇杆向左/右：舵机比例转向。
- 按下摇杆：紧急停车并解除车辆锁定。
- 急停或失联后，必须松开按键并让摇杆完全回中才能重新解锁。

注意：GPIO2属于ESP32-C3启动相关引脚之一。正常使用时不要在A板复位或刚上电过程中按住摇杆按键。

### 3.1 A板供电

原型阶段推荐使用小型USB充电宝通过USB-C给A板供电。不要把未经稳压的4节镍氢电池直接接入A板3.3V。

## 4. B板与TB6612FNG控制接线

本文建议将TB6612的A通道定义为后左电机、B通道定义为后右电机，便于未来扩展四轮差速。如果实车当前左右相反，应做好标签记录。

下面这张表是**原型/面包板接线**，不是6×8cm少飞线洞洞板的优化接线。按此表连接时，车辆端必须烧录
`rc_car_vehicle_remote_motor_test.ino`。

| TB6612FNG | B板 ESP32-C3/电源 | 用途 |
|---|---|---|
| VCC | ESP32 3.3V | 驱动板逻辑电源 |
| VM | 电池正极主分支 | 电机功率电源 |
| GND | 公共GND | 电池、ESP32、舵机共地 |
| STBY | GPIO6 | 高电平使能，失联时拉低 |
| AIN1 | GPIO3 | 电机A方向控制1 |
| AIN2 | GPIO4 | 电机A方向控制2 |
| PWMA | GPIO5 | 电机A PWM调速 |
| BIN1 | GPIO7 | 电机B方向控制1 |
| BIN2 | GPIO10 | 电机B方向控制2 |
| PWMB | GPIO20 | 电机B PWM调速 |
| AO1、AO2 | 后左电机两端 | 建议定义为后左轮 |
| BO1、BO2 | 后右电机两端 | 建议定义为后右轮 |

实车验证两个电机的安装极性都与初始逻辑方向相反，因此车辆程序当前配置为：

```cpp
MOTOR_A_DIRECTION = -1
MOTOR_B_DIRECTION = -1
```

不要为了修正整车前后方向而修改通信层；正油门始终定义为车辆前进。

## 5. B板与MG995舵机接线

| MG995线色 | 连接位置 | 说明 |
|---|---|---|
| 红色 | 电池正极大电流分支 | 不经过ESP32或面包板 |
| 棕色/黑色 | 公共GND | 接电池负极和ESP32 GND |
| 橙色/黄色 | B板 GPIO21 | 50Hz舵机控制信号 |

已实测安全舵机参数：

| 转向位置 | 控制脉宽 |
|---|---:|
| 安全最左 | 1120μs |
| 准确中位 | 1380μs |
| 安全最右 | 1640μs |

脉宽增加时车轮向右。不得在当前机械结构上超出`1120～1640μs`，以免舵机堵转或拉杆顶死。

## 6. 抗干扰电容

| 电容 | 安装位置 | 极性 |
|---|---|---|
| 1000μF、耐压≥10V | TB6612的VM与GND附近 | 正极接VM，负极条纹接GND |
| 1000μF、耐压≥10V | MG995红线与棕线附近 | 正极接红线，负极条纹接GND |
| 100nF/104陶瓷电容 | 后左电机两端，尽量靠近电机 | 无极性 |
| 100nF/104陶瓷电容 | 后右电机两端，尽量靠近电机 | 无极性 |

电解电容接反可能发热、漏液甚至损坏，通电前必须检查负极条纹方向。

## 7. 线材和布线要求

- 电池、舵机、电机、TB6612 VM和GND使用红黑20～22AWG线或约0.3～0.5mm²导线。
- GPIO控制信号可以使用杜邦线，但装车后应改为焊接或带锁连接器。
- 电机线与舵机电源线尽量远离ESP32天线和摇杆ADC线。
- 电机线可绞合，减少电磁干扰。
- ESP32天线端朝车体外侧，避免紧贴电池、电机、金属铜柱或大面积导线。
- 电池盒、控制板和电容必须机械固定，导线不得进入车轮和转向拉杆活动范围。
- 裸露焊点使用热缩管绝缘；电源正负线优先使用红、黑颜色区分。

## 9. 烧录程序时的供电顺序

车辆端使用独立5V模块后，烧录时必须避免两路5V并联：

1. 关闭车辆电池总开关。
2. 确认升降压模块输出已经消失；稳妥做法是断开模块`OUT+`与ESP32 5V之间的连接。
3. 插入USB并上传程序。
4. 上传完成后拔掉USB。
5. 恢复模块输出连接。
6. 再开启车辆电池。

遥控器A板可直接通过USB烧录。烧录和复位时不要按住摇杆按键。

## 10. 正常上电与关机顺序

推荐上电：

1. 摇杆保持中心并松开按键。
2. 开启遥控器A板。
3. 开启车辆总电源。
4. 等待约3秒，车辆完成通信和中位解锁。
5. 小幅推动摇杆确认控制方向。

推荐关机：

1. 摇杆回中。
2. 按下急停或等待车辆停止。
3. 先关闭车辆电源。
4. 再关闭遥控器。

## 11. 通电前检查表

- [ ] 电池正极没有接到ESP32 3.3V。
- [ ] 升降压模块输出已经测量为4.9～5.1V。
- [ ] USB 5V与模块5V没有同时接入。
- [ ] TB6612 VCC接3.3V，VM接电池正极。
- [ ] 电池负极、TB6612 GND、舵机GND和ESP32 GND共地。
- [ ] 两只1000μF电解电容极性正确。
- [ ] 两个电机端各有一颗100nF陶瓷电容。
- [ ] 舵机信号接GPIO21，红线没有接ESP32电源脚。
- [ ] 车轮悬空完成首次测试。
- [ ] 电源线和信号线没有进入车轮或转向机构活动范围。

## 12. 常用测量点

## 13. 常见故障定位

### 13.1 串口正常但电机不转

依次检查电池输出、TB6612 VM、VCC、STBY、AIN/BIN、AO/BO输出，以及电池负极是否与ESP32共地。

### 13.2 舵机上电乱转或不响应

立即断电，检查橙/黄信号线是否接GPIO21、舵机GND是否与ESP32共地、红线供电极性是否正确。若串口指令正常而舵机持续转动，还需确认不是360°连续旋转型号。

### 13.3 电机启动时ESP32重启或舵机抖动

检查电池电压跌落、公共GND接触、电源线是否过细、1000μF电容是否靠近负载，以及电机端100nF电容是否安装。不要通过面包板输送主电流。

### 13.4 舵机回正卡顿

当前软件每10ms最多改变6μs。如果仍卡顿，断开转向拉杆比较空载动作：空载顺畅通常说明转向节或拉杆摩擦、几何死点或舵机安装偏斜；空载仍抖动则检查供电和信号地。

### 13.5 急停后车辆不再运行

这是正常安全逻辑。松开摇杆按键，并让前后、左右两个轴都回到中心，系统才会重新解锁。

## 15. 四轮差速扩展预留

V1继续使用舵机转向。未来改装为四轮差速时，可增加第二块TB6612：

- 当前TB6612 A通道控制后左电机，B通道控制后右电机。
- 新增TB6612 A通道控制前左电机，B通道控制前右电机。
- 两块驱动板共享`AIN1/AIN2/PWMA`、`BIN1/BIN2/PWMB`和`STBY`控制网络。
- 软件执行层改为`left = throttle + steering`、`right = throttle - steering`。
- 通信数据包仍保持`throttle / steering / buttons / sequence`，无需修改遥控器协议。

扩展前必须重新测量四个电机的启动与堵转电流，并核算电池、开关、保险丝、线径、连接器和两块驱动板的散热余量。
