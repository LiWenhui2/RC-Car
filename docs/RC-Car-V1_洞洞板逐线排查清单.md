# RC-Car V1 洞洞板逐线排查清单

适用程序：`software/arduino/tests/rc_car_vehicle_remote_motor_test/rc_car_vehicle_remote_motor_test.ino`

适用GPIO：AIN1=3、AIN2=4、PWMA=5、STBY=6、BIN1=7、BIN2=10、PWMB=20、SERVO=21。

> 检查焊接面时，左右方向与元件面相反。以下全部以模块自身丝印为准，不以照片中的左右位置为准。

## 0. 检查前

- [ ] 断开电池。
- [ ] 拔掉USB。
- [ ] 电池开关关闭。
- [ ] 如果使用排母，拔下ESP32和TB6612。
- [ ] 万用表切换到通断档；只有断电时才使用通断档。

## 1. 公共GND网络

以下任意两点之间都应持续蜂鸣，目标电阻接近0Ω：

- [ ] 电池盒负极。
- [ ] 升降压模块IN−。
- [ ] 升降压模块OUT−。
- [ ] ESP32 GND。
- [ ] TB6612所有标为GND的引脚。
- [ ] 舵机棕色/黑色线端子。
- [ ] C1负极。
- [ ] C2负极。

如果舵机和电机同时不动作，优先检查这一组。

## 2. VBAT电池正极网络

电池开关打开后，以下位置属于同一个VBAT网络：

- [ ] 电池盒开关后的正极。
- [ ] TB6612 VM。
- [ ] 舵机红线端子。
- [ ] 升降压模块IN+。
- [ ] C1正极（驱动板附近1000μF）。
- [ ] C2正极（舵机供电附近1000μF）。

断电通断检查时这些点应互相导通。VBAT不得直接连接ESP32的5V或3.3V。
  

- [ ] 升降压模块OUT+只连接ESP32的5V输入。
- [ ] 升降压模块OUT−连接公共GND。
- [ ] 5V不得连接TB6612 VM。
- [ ] 5V不得连接TB6612 VCC。
- [ ] 5V不得连接舵机红线。
- [ ] 使用升降压模块给ESP32供电时，不同时插USB。

## 4. 3.3V逻辑网络

- [ ] ESP32 3.3V只连接TB6612 VCC。
- [ ] TB6612 VCC没有误接VM。
- [ ] 3.3V与GND之间不持续蜂鸣。
- [ ] 3.3V与5V/VBAT之间不持续蜂鸣。

## 5. TB6612控制信号

逐条检查，起点与终点应导通，且不得与相邻GPIO短路：

| 完成 | ESP32实际丝印引脚 | TB6612实际丝印引脚 |
|---|---|---|
| [ ] | GPIO3 | AIN1 |
| [ ] | GPIO4 | AIN2 |
| [ ] | GPIO5 | PWMA |
| [ ] | GPIO6 | STBY |
| [ ] | GPIO7 | BIN1 |
| [ ] | GPIO10 | BIN2 |
| [ ] | GPIO20 | PWMB |

每检查一条，还要确认该线对GND、3.3V、5V和相邻信号线均不持续蜂鸣。

## 6. 舵机信号

- [ ] ESP32实际GPIO21与舵机橙色/黄色信号端子导通。
- [ ] GPIO21没有误接GPIO20。
- [ ] GPIO21与VBAT、5V、3.3V、GND均不持续蜂鸣。
- [ ] 舵机插头顺序确认：棕/黑=GND，红=VBAT，橙/黄=GPIO21。

## 7. 电机输出

- [ ] TB6612 AO1连接后左电机端子1。
- [ ] TB6612 AO2连接后左电机端子2。
- [ ] TB6612 BO1连接后右电机端子1。
- [ ] TB6612 BO2连接后右电机端子2。
- [ ] AO1与AO2没有短路。
- [ ] BO1与BO2没有短路。
- [ ] 每只100nF陶瓷电容直接跨接在对应TT电机的两个端子之间。

## 8. 全板短路检查

模块尽量拔下后检查：

- [ ] VBAT与GND不持续蜂鸣。
- [ ] 5V与GND不持续蜂鸣。
- [ ] 3.3V与GND不持续蜂鸣。
- [ ] VBAT与5V不持续蜂鸣。
- [ ] VBAT与3.3V不持续蜂鸣。
- [ ] 5V与3.3V不持续蜂鸣。

电解电容充电可能使蜂鸣器短暂响一下；持续蜂鸣才表示需要排查。

## 9. 分阶段通电

### 阶段A：只测升降压模块

- [ ] 不安装ESP32、TB6612、舵机和电机。
- [ ] 接入电池，测IN+对IN−约4.8～5.6V。
- [ ] 测OUT+对OUT−为4.9～5.1V。
- [ ] 输出不正确时立即断电调整，禁止连接ESP32。

### 阶段B：安装ESP32

- [ ] 断电后安装ESP32，不插USB。
- [ ] 通电测ESP32 5V对GND为4.9～5.1V。
- [ ] 测ESP32 3.3V对GND约3.3V。

### 阶段C：安装TB6612但暂不接电机

- [ ] 断电后安装TB6612。
- [ ] 通电测VM对GND约4.8～5.6V。
- [ ] 测VCC对GND约3.3V。
- [ ] 遥控器解锁后推动油门，测STBY对GND约3.3V。

### 阶段D：先接舵机

- [ ] 断电后接舵机，车轮机构悬空。
- [ ] 测舵机红线对棕线约4.8～5.6V。
- [ ] B板串口中servo在1120～1640μs变化时，舵机应对应转向。
- [ ] 若串口变化但舵机不动，断电后用临时杜邦线将实际GPIO21直接接舵机信号，绕过洞洞板走线复测。

### 阶段E：最后接电机

- [ ] 断电后接两个电机并将车轮架空。
- [ ] 推动油门时B板串口应显示state=DRIVE、applied非0。
- [ ] STBY应约3.3V。
- [ ] 若STBY正常但电机不转，测AO1-AO2和BO1-BO2之间是否出现输出电压。

## 10. 当前故障最优先的四项

1. [ ] 电池负极与ESP32 GND是否真正导通。
2. [ ] 舵机红/棕线之间是否实测有4.8～5.6V。
3. [ ] TB6612 VM-GND是否实测有4.8～5.6V。
4. [ ] 实际GPIO21到舵机信号端子是否导通且没有因焊接面镜像接到GPIO20。
