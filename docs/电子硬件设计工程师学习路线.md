# 电子硬件设计工程师学习路线

> 目标：从需求分析、原理图与 PCB 设计，一直做到生产、上电调试、测试和改版。适合已有少量电路基础、希望系统学习的人。
>
建议把时间安排看作学习节奏，而不是硬性毕业期限。每阶段都要做实物，留下计算、测量和改版记录。

## 一、要建立的完整能力

```text
需求与约束 → 系统框图 → 功耗/接口预算 → 器件选型 → 原理图
→ 设计审查 → PCB → 生产文件 → SMT/组装 → 分阶段上电
→ 功能与可靠性测试 → 故障分析 → 改版
```

一名能够独立交付硬件的工程师，应能回答四类问题：电路为什么这样设计、PCB 中电流如何流动及返回、板子出现异常时如何测量定位、工厂如何稳定地生产和测试它。

## 二、分阶段学习路线

| 阶段 | 建议投入 | 核心课程与技能 | 实践成果 | 进入下一阶段的标准 |
| --- | --- | --- | --- | --- |
| 1. 电路与实验基础 | 1–2 个月 | 电路分析；R、C、L、二极管、BJT、MOSFET；数字电平；万用表、限流电源、焊接 | LED、按键、MOSFET 负载控制和 RC 滤波实验 | 能计算限流、分压、功耗和时间常数；能安全测量电压、电流与短路 |
| 2. 模拟与电源 | 2–3 个月 | 运放、比较器、ADC 输入调理；LDO、Buck/Boost；去耦、纹波、瞬态、热设计；电池与保护 | 3.3 V 电源板和电池电压采集板 | 能根据输入范围、峰值电流和温升选电源，并用示波器核对 |
| 3. MCU 与接口 | 2–3 个月 | C 语言；GPIO、PWM、ADC、中断、看门狗；UART、I²C、SPI、USB；时钟、复位、启动与下载 | 一块可下载、可调试的 MCU 最小系统板 | 能独立阅读数据手册，画出上电、启动、下载和调试电路 |
| 4. 原理图与 PCB | 2–4 个月 | 器件库与封装；ERC/DRC；两层/四层板；回流路径、地平面、去耦布局；Gerber、BOM、贴片坐标 | 完成两层控制板和四层主控板各一版 | 每个关键器件和走线都能解释其作用、封装和制造限制 |
| 5. 电机、EMC 与射频 | 3–6 个月，与项目并行 | H 桥、电机堵转电流、PWM、编码器；ESD/浪涌；开关电源布局；传输线、50 Ω 射频馈线与天线匹配 | 小车电源/驱动板；裸芯片无线最小系统板 | 在电机启停和无线通信同时工作时能定位复位、干扰和链路问题 |
| 6. 生产与产品化 | 贯穿全程 | DFM/DFA、钢网与回流焊、测试点、治具、失效分析、替代料、版本与测试记录 | 第二版 PCB、装配资料、上电流程和测试报告 | 同一设计能被别人按文件装配、烧录、测试并复现结果 |

这些阶段会重叠。比如学习 MCU 时就应开始画 PCB；学习生产时要回头修改封装、测试点和装配工艺。

## 三、按课程主题学习什么

### 1. 电路分析与器件

- 电压、电流、功率、基尔霍夫定律、戴维南等效。
- RLC 暂态、滤波、频率响应与谐振。
- 二极管、BJT、MOSFET 的工作区和额定值。
- 数字高低电平、上拉/下拉、开漏输出、3.3 V/5 V 兼容。
- 读数据手册：绝对最大额定值、推荐工作条件、典型电路、时序与封装。

### 2. 模拟、电源与电池

- 运放、比较器、分压采样、ADC 参考与输入范围。
- LDO 与开关稳压器的效率、纹波、热耗散和布局。
- 去耦、储能电容、接地、电源支路和瞬态电流。
- 电池放电曲线、低压保护、反接保护、保险丝与电源切换。
- 从电机堵转、舵机瞬态和无线发射峰值出发，做电流预算。

### 3. 数字与嵌入式

- MCU 启动链路：供电 → 复位 → 时钟 → 启动配置 → Flash → 固件。
- GPIO、定时器、PWM、ADC、DMA、看门狗与低功耗。
- UART、I²C、SPI、USB 的物理连接和调试方法。
- C 语言、构建与烧录、日志、状态机、异常处理、Git 版本管理。

### 4. PCB 与电磁兼容

- 封装尺寸、Pin 1、焊盘、阻焊、钢网、钻孔与装配方向。
- 信号与电源的返回路径；连续参考地平面；去耦电容位置。
- 开关电源热回路、大电流线宽、差分线与阻抗控制。
- ESD、传导与辐射干扰、电缆和连接器的影响。
- 射频馈线、匹配网络、天线净空及整车机械布局。

### 5. 生产与调试

- 原理图 ERC、PCB DRC、BOM/封装/坐标一致性检查。
- PCB 制造、SMT、钢网、回流焊、AOI、X-Ray 和返修。
- 上电前检查、限流上电、分电源域测量、逐功能验证。
- 功能测试、温升、堵转、失联、欠压和长时间运行测试。
- 记录“预期值、实测值、结论、修改”，形成改版依据。

## 四、结合 RC 小车的项目阶梯

当前项目已有 ESP-NOW、双后轮电机、舵机转向与失联停车验证。下面的顺序让每块新板都只增加一两个主要未知点，同时最终覆盖裸芯片设计。

1. **实验板**：MOSFET 控制负载、按键、LED、分压测量。练习基本计算和仪器。
2. **独立电源板**：电池输入、保护、3.3 V 逻辑电源、舵机/电机分支。验证启动、堵转和电压跌落。
3. **电机驱动板**：集成 H 桥芯片、接口、储能与抑制元件。测空载、启动和堵转电流。
4. **ESP32-C3 裸芯片最小系统板**：电源、时钟、复位、BOOT、USB/UART、射频匹配和天线。先验证烧录、无线及电流，再接入小车。
5. **四层小车主板**：整合控制、电源、驱动、接口和测试点。按功能分区验证。
6. **第二版产品板**：根据实测记录修正封装、走线、抗干扰、热设计和可测试性。

前两块板可以使用现有开发板做功能对照；最终主控板按你的目标使用 ESP32-C3 裸芯片。做射频部分时，以乐鑫官方硬件设计指南和所选芯片的最新版数据手册为准。具体型号、供电和引脚应在绘图前重新核对，而不是仅凭 SuperMini 板级资料。

### 每块板都交付的最小文件集

- 一页需求：输入电压、接口、峰值电流、尺寸与工作条件。
- 系统框图、引脚表、电源预算和关键计算。
- 原理图、PCB、器件清单、封装来源及版本号。
- ERC/DRC 记录、Gerber、钻孔、贴片坐标和装配图。
- 上电检查表、测量数据、问题清单与改版结论。

## 五、参考书目：按阶段读

书不必一次买齐。先选一本入门主线书，配合实验；遇到具体设计问题再查进阶书。下面保留英文原书名，便于确认版本。

| 阶段 | 书目 | 怎样使用 |
| --- | --- | --- |
| 入门 | Paul Scherz、Simon Monk，[*Practical Electronics for Inventors*, 4th ed.](https://www.mheducation.com/highered/mhp/product/practical-electronics-inventors-fourth-edition.html) | 从元件、基础电路和测量章节开始；每读一种电路就搭建、计算和测量一次。 |
| 电路设计参考 | Paul Horowitz、Winfield Hill，[*The Art of Electronics*, 3rd ed.](https://www.cambridgebookshop.co.uk/products/the-art-of-electronics) | 作为长期案头参考，重点查电源、模拟接口、数字接口、噪声和测量；不要求从头顺序读完。 |
| 嵌入式系统 | Elecia White，[*Making Embedded Systems*, 2nd ed.](https://www.oreilly.com/library/view/making-embedded-systems/9781098151539/) | MCU 最小系统能运行后阅读；结合小车练习系统架构、调试和制造需求。 |
| 信号完整性进阶 | Howard Johnson、Martin Graham，[*High-Speed Digital Design: A Handbook of Black Magic*](https://www.pearson.com/en-us/subject-catalog/p/Johnson-High-Speed-Digital-Design-A-Handbook-of-Black-Magic/P200000009388/undefined) | 做四层板并遇到反射、串扰或参考平面问题后选读；内容较深，部分器件案例年代较早。 |
| EMC 进阶 | Mark I. Montrose，[*Printed Circuit Board Design Techniques for EMC Compliance*, 2nd ed.](https://www.wiley-vch.de/en?isbn=9780780353763&option=com_eshop&view=product) | 结合电机启停造成的复位、USB 掉线和无线性能下降等实际故障阅读。 |
| 开关电源进阶 | Christophe P. Basso，[*Switch-Mode Power Supplies: SPICE Simulations and Practical Designs*, 2nd ed.](https://books.google.com/books/about/Switch_Mode_Power_Supplies_Second_Editio.html?hl=en&id=oHbhAgAAQBAJ) | 在能设计和测量基础 Buck 电源后选读，用于深入理解控制环路与仿真。 |

### 免费且应常查的原厂资料

- [乐鑫 ESP32-C3 硬件设计指南](https://documentation.espressif.com/esp-hardware-design-guidelines/zh_CN/latest/esp32c3/index.html)：裸芯片原理图、时钟、电源、射频、USB 与 PCB 布局的首要依据。
- [乐鑫 ESP32-C3 芯片数据手册](https://documentation.espressif.com/esp32-c3_datasheet_cn.pdf)：引脚、电气参数、启动配置与封装。
- [TI《开关电源布局指南》AN-1149](https://www.ti.com/lit/pdf/SNVA021)：学习 Buck 布局和关键电流回路。
- 选定电机驱动器、稳压器和保护器件的**原厂数据手册、评估板原理图及布局指南**：最终参数以具体型号和实际版本为准。

## 六、建议的每周节奏

- 每周 2 次理论学习：每次围绕一个可测的问题，例如“为什么电机启动会让 3.3 V 下跌”。
- 每周 2 次实验或设计：搭电路、画原理图、布板、焊接或调试。
- 每周 1 次复盘：整理计算、示波器截图、错误与待验证假设。

学习时间大致可按 **30% 理论、50% 实作、20% 资料阅读与复盘** 分配。第一年优先完成至少两次“设计 → 制造 → 测量 → 改版”的闭环。衡量进步的主要依据是你能否用计算和实测解释设计，而不是画过多少张图。
