# PCB 生产文件目录说明

本目录只保存从已检查通过的 PCB 设计导出的生产和装配文件，不保存主要设计源文件。

| 目录 | 用途 |
|---|---|
| `gerber` | PCB 各铜层、阻焊层、丝印层、钢网层和板框层等 Gerber 文件。 |
| `drill` | Excellon 钻孔文件及钻孔说明，包括电镀孔、非电镀孔和槽孔。 |
| `assembly` | 元器件坐标、装配图、贴片图、位号图以及装配说明。 |
| `bom` | 生产版本的物料清单，记录位号、数量、规格、封装和制造商料号。 |

每次输出前应先完成 ERC、DRC 和 Gerber 独立检查。不同 PCB 版本建议建立带版本号和日期的子目录，避免覆盖已投产文件。
